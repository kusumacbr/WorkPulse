# PRODUCT.md — WorkPulse

## Product Truth

### 1. Audience
- **Primary**: HR Administrators, Operations Managers, Team Leads.
- **Secondary**: Individual Employees across hybrid/remote/on-site work setups.

### 2. Purpose
WorkPulse is an all-in-one workforce management platform designed for modern enterprises. It provides seamless tracking for attendance, work-mode requests (hybrid/WFH/office), leave applications, goal alignment, and performance review workflows.

### 3. Operating Context
- **Environment**: Desktop web (1440px+ standard), tablet responsive, high-density dashboard layouts.
- **Usage Pattern**: Daily check-ins/check-outs, weekly manager approvals, quarterly performance reviews.
- **Data Density**: High-density data tables, real-time status indicators, interactive filters, and action modals.

### 4. Technical Stack & Constraints
- **Framework**: Next.js 15 (App Router), React 19, TypeScript.
- **Styling**: Tailwind CSS, Class Variance Authority (`cva`), Framer Motion, Lucide Icons.
- **Database/Backend**: Prisma ORM, Supabase PostgreSQL, Supabase SSR.
- **3D & Visualization**: `@react-three/fiber`, `@react-three/drei`, `three`, `canvas-confetti`.
- **Theme Support**: Seamless Dark Mode / Light Mode styling with tailored contrast.

### 5. Brand Voice & Tone
- **Professional & Crisp**: Executive-ready UI with clear visual hierarchy.
- **Responsive & Dynamic**: Micro-animations for feedback without overwhelming users.
- **Clear Status Communication**: Instant visual distinction between Pending, Approved, Rejected, and Active states.
